01 THE WORKFLOW

From first import
to a considered change.

Every step leaves room for a person to inspect what the model sees and decide what happens next.

  1. 01
    01 / INTAKE

    Bring in a message

    Import CSV, EML, or MBOX files, use synthetic examples, or connect read-only Gmail when configured.

  2. 02
    02 / SUGGESTION

    Let the model sort

    Each email gets a category and priority suggestion with confidence cues.

  3. 03
    03 / HUMAN REVIEW

    Read and correct

    Confirm the labels that fit. Only saved human feedback can train a candidate.

  4. 04
    04 / CANDIDATE

    Prepare a comparison

    Build a candidate from confirmed feedback while the active model stays in place.

  5. 05
    05 / EVALUATION

    Check before activation

    Inspect prediction changes and held-out evaluation before choosing to activate.

  6. 06
    06 / REVERSIBLE

    Restore when needed

    Earlier versions remain available in the ledger for a deliberate rollback.

    03 MODEL CONTROL

    Learning stays deliberate.

    InboxLearn separates the inbox predictions people review from the models they choose to activate.

    A

    Corrections are explicit

    Only saved human feedback can contribute labels to candidate training. Predictions are not silently recycled as truth.

    B

    Candidates wait

    Preparing a candidate does not change active predictions. Compare the candidate and run evaluation before activating it.

    C

    Results stay visible

    Evaluation reports compare versions on the selected held-out data. Synthetic examples demonstrate mechanics, not real-world accuracy.

    D

    Earlier versions remain available

    Use the version history to restore a previous model when a change is not useful.
