01 How it works

From first import
to a considered change.

Six steps, one thread. Every step leaves room for you to inspect what the model sees and decide what happens next.

  1. 01
    Intake

    Bring in a message

    Import CSV, EML, or MBOX files, use synthetic examples, or connect read-only Gmail when configured.

  2. 02
    Suggestion

    Let the model sort

    Each email gets a category and priority suggestion with confidence cues. Uncertain messages are routed to you.

  3. 03
    Human review

    Read and correct

    Confirm the labels that fit. Only saved human feedback can train a candidate.

  4. 04
    Candidate

    Prepare a comparison

    Build a candidate from confirmed feedback while the active model stays in place, then compare what it would change.

  5. 05
    Evaluation

    Check before activation

    Inspect prediction changes and held-out evaluation before choosing to activate. Evaluation never guarantees improvement.

  6. 06
    Reversible

    Restore when needed

    Earlier versions remain available in the ledger for a deliberate rollback. Your feedback stays.

    03 Model control

    Learning stays
    deliberate.

    InboxLearn separates the predictions people review from the models they choose to activate.

    ACorrections are explicit
    Only saved human feedback can contribute labels to candidate training. Predictions are not silently recycled as truth.
    BCandidates wait
    Preparing a candidate does not change active predictions. Compare the candidate and run evaluation before activating it.
    CResults stay visible
    Evaluation reports compare versions on the selected held-out data. Synthetic examples demonstrate mechanics, not real-world accuracy.
    DEarlier versions remain available
    Use the version history to restore a previous model when a change is not useful.
