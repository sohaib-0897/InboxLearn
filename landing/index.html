01 THE WORKFLOW

A useful prediction
knows when to ask.

Suggestions help sort the work. Confirmed human feedback and explicit model controls determine what changes.

  1. 01
    BRING IT IN

    Import email

    Load CSV, EML, or MBOX files, or start with the bundled synthetic examples. Read-only Gmail import is available when configured.

  2. 02
    GET A SUGGESTION

    Classify and route

    The model suggests a category and priority. Messages below your review thresholds are easy to find.

  3. 03
    KEEP A PERSON IN THE LOOP

    Review and confirm

    Read the message, then save the labels you confirm. A prediction by itself is never treated as a training label.

  4. 04
    CHANGE MODELS DELIBERATELY

    Evaluate, activate, or roll back

    Prepare a candidate from saved feedback, inspect prediction changes, and evaluate it before activation. Earlier versions can be restored.

    03 MODEL CONTROL

    Learning stays deliberate.

    InboxLearn separates the inbox predictions people review from the models they choose to activate.

    A

    Corrections are explicit

    Only saved human feedback can contribute labels to candidate training. Predictions are not silently recycled as truth.

    B

    Candidates wait

    Preparing a candidate does not change active predictions. Compare the candidate and run evaluation before activating it.

    C

    Results stay visible

    Evaluation reports compare versions on the selected held-out data. Synthetic examples demonstrate mechanics, not real-world accuracy.

    D

    Earlier versions remain available

    Use the version history to restore a previous model when a change is not useful.
